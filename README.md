# wooseong97.github.io

Personal academic website of **Wooseong Jeong**, Ph.D. Candidate at KAIST.

🔗 https://wooseong97.github.io

Built with [Jekyll](https://jekyllrb.com/) (based on the [al-folio](https://github.com/alshedivat/al-folio) theme) and deployed to GitHub Pages.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

The site is automatically built and deployed by the `Deploy site` GitHub Action on every push to `main`.
